# Cómo se mide una pieza de belleza

La rúbrica es la del jurado de SaleADS (D24) mirada con ojos de belleza. Cada punto es una pregunta, no una nota fija.

| Punto | Pregunta en belleza |
|---|---|
| Fidelidad | ¿El producto es el real del dueño (empaque, color, textura) y no uno parecido? |
| Avatar | ¿La persona y el entorno se parecen a quien compra (edad, tono de piel, estilo de vida)? |
| Dolor | ¿Se nota la molestia o el deseo real (piel reseca, falta de tiempo, cabello sin forma)? |
| Ángulo | ¿Se entiende el ángulo de la apuesta sin leer el texto largo? |
| Resuelve | ¿Se ve cómo el producto ayuda, con uso o rutina, sin prometer un resultado médico? |
| Gancho | ¿Hay algo que detiene el dedo en el primer segundo (textura, gesto, contraste)? |

Además, cuando haya dos o más piezas candidatas, el owner puede elegir **a ciegas** cuál prefiere (sin saber cuál es
del kit). Esa preferencia se anota como señal para mejorar el kit, no como regla.

Si una pieza falla en fidelidad, el jurado avisa y tú decides; se lo cuentas al dueño. Nada se bloquea solo.
