# Cross-team dependencies
1. Trace requester → responsible party → expected delivery → deadline → confirmation → evidence → sales impact.
2. A broken dependency needs a concrete missing, late or contradictory state; silence alone is insufficient.
3. State severity and confidence separately.
4. Recommend the smallest intervention and track it as a loop.
