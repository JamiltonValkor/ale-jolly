# Decision support
1. Name the decision, deadline and affected goal.
2. Present verified context and relevant history before recommending.
3. Compare realistic options by impact, reversibility, dependencies and risk.
4. Distinguish your recommendation from an actual explicit owner decision. Preserve only the actual authenticated owner's original answer as owner evidence; the automatic curator consolidates it. An assistant_proposed recommendation remains a proposal until real confirmation. Do not call a legacy local-memory writer or infer commercial approval.
5. Ask the smallest decisive question when evidence is missing.
