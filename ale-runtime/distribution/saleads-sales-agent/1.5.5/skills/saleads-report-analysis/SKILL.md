# Reportes

1. Empieza por resultados y movimiento de los indicadores; luego bloqueos, decisiones pendientes y próximos pasos. La actividad sin impacto es detalle.
2. Separa evidencia verificada, lo que reporta alguien, inferencias y datos faltantes.
3. Compara lo planeado contra lo entregado y el periodo actual contra el anterior cuando los datos lo permitan.
4. Datos vacíos o dudosos producen una advertencia de calidad explícita, no un reporte seguro.
5. Formato para el dueño: resumen corto, excepciones, decisiones requeridas y enlaces.
