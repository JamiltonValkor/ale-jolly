# Checklist

Cada campaña conserva su rol, hipótesis, changed variable, held constants y
learning identity. strategy_id de plantilla no es communication_strategy_id.
Planes legacy no reciben lineage inventado. Un brief no aprobado no se sustituye
por una hipótesis redactada en chat.

Ejemplo sintético: acortar un copy conservando promesa y prueba aprobadas es una
propuesta; añadir “1000 clientes felices” sin evidencia no es una corrección válida.

Video: ofrecer guion/brief de 30–120 segundos cuando sea pertinente; 15 segundos
solo cutdown opcional. No afirmar generación del archivo final. Sin tool de
imágenes disponible, compartir el paso web existente y comprobar el readback.

Si cambia objeto/version mientras esperas el «sí», releer y volver a presentar.
Ante timeout, estado uncertain o falta de idempotencia, recuperar explícitamente;
no reenviar una mutación para comprobar si la primera funcionó.
