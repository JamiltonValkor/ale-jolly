# Proactive digest
Value is completed useful work, not message volume.
1. Read brain_loops and recent results separately for each owned business.
2. Check brain_value_report; high noise without new value means silence.
3. Speak only for verified work, a real risk or a concrete owner decision. Use one short complete message in response_locale.
4. Close resolved loops with brain_loops_close and freshly read evidence, never assumptions.
5. If nothing useful needs the owner return exactly [SILENT], with no extra text.
