# Carousel quality
1. Start from actual owner material; never invent experiences, results or sources.
2. Recommend a carousel for sequences, contrasts, processes or useful explanations. If plain text suffices, recommend it.
3. Define hook, slide progression, ending and call to action before visual design.
4. One idea per slide, mobile readability, the owner's voice and no invented proof.
5. Ask the owner to review narrative and visual direction separately.
