# Infoproducts — four launch phases
Source: SaleADS special-date infoproduct catalog v3 r3. Adapt the original event date to the class/offer opening date. If no date exists, propose a concrete local day/time 12–18 days ahead (18 recommended); it is a proposal until the owner confirms. A changed date shifts windows, not the work identity. Missing registration page and date confirmation remain before-activation prerequisites, not invented facts. In proposal-only mode prepare the schedule artifact without remote campaign creation.

The avatar/problem is the same as other months. The date explains when/why decide now, not who the audience is or what the product does.

| Phase | Goal | Reference window | Destination |
|---|---|---|---|
| Acquisition | Registrations around the actual class problem | 12–18 days before class, ideally18; end at class start | Registration web page with pixel |
| Anticipation | Prepare registrants for opening | 6 windows of24h before class | Instagram/remarketing |
| Sale | Approved offer, distinct campaign angles | End of class to close, at least4days | Web/WhatsApp |
| Closing | Actual closing-date urgency | 4 windows of24h to close | WhatsApp |
Class starts and ends the same day. See references/fases.md.

Only owner-approved promises/offers/prices and actual owner-provided/confirmed evidence. Never invent testimonials, initials, results, certifications, guarantees, discounts, slots, stock or countdowns. A non-discount offer remains non-discount. Anticipation has no price, discount or buy-now language. Social proof, expert consensus, safety, authority, guarantee/risk reversal and result claims require real evidence; request it before discarding a useful bet. Curiosity, actual date, pain/pleasure, simplicity, comparison, positivity, loss aversion and stereotype challenge need no fabricated proof.

## Structure
Acquisition: web image/video, reference ABO4adsets and CBO comparison, requiring page/site/pixel. Anticipation: remarketing registered/engaged/visitors, fresh image per daily window. Sale: web video and WhatsApp image, separate benefit/objection/simplicity angles with their own base image. Closing: WhatsApp image campaign with4windows. Retention references0–180days. Exclude unavailable web/WhatsApp/Instagram/pixel resources and say why. No fixed phase allocation; reference minimum around2USD/day/adset, adjusted to learning and approved total. Base1:1 and feed4:5 images;9:16UGC video delivered as a production script, not a rendered file.

Later authorized commercial publishing is PAUSED; owner approves activation. Pause/reallocation within approved monthly total is distinct from activation/deletion/exceeding it. Proposal-only first work authorizes no commercial writes.

## Read and learn
Acquisition: registration cost and attendance. Sale/closing: purchases/CPA with actual owner lead feedback. Compare angles only in the same phase/window after sufficient evidence; won in this test is not universal causality. Do not repeat losing angles without new evidence. Store dated phase, angle, evidence and actual owner decisions business-bound.
