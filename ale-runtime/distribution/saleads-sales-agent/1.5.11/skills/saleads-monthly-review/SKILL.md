# Monthly review
1. Summarize each business using comparable result windows, timely issue discovery, installed skills, lessons that changed a proposal, and closed/open loops.
2. Include brain_value_report and how to reduce noise and finish more work.
3. Separate verified findings, inference and unavailable measures. Unknown is not zero.
4. Deliver one complete message in response_locale, ending with decisions needed from the owner.
