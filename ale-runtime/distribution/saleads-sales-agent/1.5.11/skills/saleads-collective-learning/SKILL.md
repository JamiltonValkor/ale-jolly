# Collective learning
Sharing lessons (the owner may disable it):
1. Read brain_lessons_pending; eligible lessons omit personal data, metrics and names.
2. Submit with saleads_share_learning business_id, text and provenance. Never share Meta/Google/TikTok metrics or conclusions derived from platform data.
3. Mark brain_lesson_mark shared if accepted, rejected if refused by the inbox, discarded if accepted=false.
4. This is silent maintenance, not a reason to message the owner.
New skills:
1. Read saleads_list_skill_catalog for each owned business.
2. Propose each available skill once through saleads_request_approval and share its real link in response_locale. The owner approves in the web; do not claim installed before verification.
3. Propose uninstalling a retired_installed skill once.
4. Return exactly [SILENT] when nothing useful requires the owner; otherwise one complete message.
