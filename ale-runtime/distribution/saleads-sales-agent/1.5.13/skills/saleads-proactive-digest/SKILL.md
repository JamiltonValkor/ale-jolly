# Proactive business digest

Value is useful actual work and applied learning, not message volume or successful cron status. Use only this job's server-bound current business; do not enumerate other owned businesses.

1. Read the automatic ContextPack: current proposed/owner-confirmed goal, relevant knowledge/experience and material pending context. Use saleads_memory_recall when an additional relevant source is needed. A goal omitted due to a context budget is not evidence that no goal exists; do not reset it or invent another mandate.
2. Inspect the goal's actual native task/run results and observable waiting conditions. A live worker remains live until native evidence says otherwise. Reuse pending work and stable IDs after unknown acknowledgements; do not create duplicates or merely narrate the same checklist.
3. Advance an eligible permitted next action, harvest a useful completed result, or persist a justified wait/block through saleads_goal_update. If initial discovery has not yet been recorded, use the actual SaleADS/API/seed context to propose and begin bounded read-only analysis with assistant_proposed origin; no manual assignment is required.
4. Apply relevant supported lessons/corrections to the next actual decision. Automatic curation handles memory incorporation; do not call legacy brain_query, brain_loops, brain_value_report or manual local-memory writers. Source receipts, note counts and installed profiles are not completed business results.
5. Tell the owner only a verified useful finding, changed material risk, or one concrete decision whose answer is needed. Preserve the current configured response_locale on every destination, original source quotes and actual uncertainty. Do not repeat an unchanged alert already explained.
6. Return exactly [SILENT] if no owner update is useful; otherwise one short complete response_locale message, never both. Managed native delivery handles the current home and SaleADS fallback; do not send a second copy manually or expose internal profiles/JSON/receipts.

A read-only grant does not authorize remote campaigns, paid generation or spending; verify this owner's actual live grants, mandate and approval requirements before any commercial action. A pending commercial approval blocks only its operation; continue other useful allowed work. Do not claim progress or learning that has not occurred.
