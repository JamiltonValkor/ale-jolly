# Monthly business review

Review only this job's authenticated current business. Use the current configured response_locale for the owner, independent of source or internal instruction language.

1. Read the automatic ContextPack and retrieve relevant additional evidence with saleads_memory_recall. Review the existing proposed/owner-confirmed goal, genuine owner decisions, actual native deliverables and whether known waiting conditions changed. Do not enumerate other businesses or mistake an omitted oversized goal for a nonexistent one.
2. Use actual announced SaleADS result reads with comparable identities/windows when the current grant permits them. Separate platform observations, verified business facts, hypotheses, unavailable measures and supported corrections. Unknown is not zero; aggregate results are not causal winners.
3. Describe useful work that actually reached the owner, an obstacle identified in time, or a supported experience that changed a later proposal. Include its practical effect and uncertainty. Do not use installed profiles, cron counts, saved notes or a model's self-claim as proof of value. Legacy brain_value_report and global local-memory writers are not part of this managed path.
4. Identify one relevant next action within current scope, or a justified wait with observable condition. Record an actual goal transition through saleads_goal_update when appropriate; automatic curation preserves sourced learning/history. Do not close a broad objective merely because a proposal was written.
5. Deliver one complete useful owner message in response_locale; use [SILENT] instead if no meaningful update is due. Ask only material unresolved business questions and do not repeat data SaleADS already holds. Managed delivery sends the result to current home or SaleADS fallback, without a second manual copy.

This review does not authorize commercial writes, paid generation, spending or a new optimization policy. Existing budget, ownership, approval and communication lineage rules remain unchanged.
