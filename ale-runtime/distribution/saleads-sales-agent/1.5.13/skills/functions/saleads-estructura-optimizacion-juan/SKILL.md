# Structure and optimization — Juan Diego Libreros methodology
This is a reasoning method, not a rigid form. Every criterion has a rationale and an applicability signal. Prefer actual business evidence; explain departures. Read references/metodo.md and references/arbol.md.

## Before deciding
Read existing bets, avatar/angle/format, prior wins/losses and the monthly limits Ale supplies: approved, spent, committed and remaining. Give numeric budget proposals within the remainder, allowing each box at least one target result cost and 3 or more days for a valid reading. If insufficient for all boxes, propose fewer and explain. If limits are missing, identify that gap; any owner-stated number remains a proposal unless verified approved. Ask what this round should learn before choosing structure.

## Structure criteria
1. CBO for learning: new bets without a proven winner; Meta allocates among responsive boxes.
2. ABO for scaling validated ads: control budget by box and expand audiences; unvalidated ads can waste budget.
3. Three coherent ads per box: same avatar/angle, varied expression. Use a master and two intentional variations of scene, person or hook. Fewer strong ads are preferable only when three useful ones cannot be made; state why.
4. Consolidate instead of duplicating: two identical CBOs compete and fragment learning. Consider adding a box to the existing campaign.
5. A new campaign is justified by a changed objective, for example moving stable winners to cost cap, not merely another copy of the same objective.

## Optimization criteria
1. Scale a winner with margin: CPA clearly below target (reference below 70%), step 50–100% about every 3 days, then reread. Do not treat reference figures as rules.
2. Falling performance: more distinct ads, not more budget. If new ads fail after sufficient evidence, reduce budget while learning.
3. Stable winners: cost cap somewhat above achieved CPA can seek more sales at that cost.
4. Pause/replace losing bets; do not repeat them. If nothing wins, examine audience, offer or product before increasing spend.

## Non-negotiable scope
All commercial moves fit the owner's approved monthly media budget. Within authorized commercial scope Ale can pause/reallocate; activation, deletion or exceeding that total needs owner web approval. The first proposal-only work creates no remote commercial objects or paid creative jobs, even PAUSED. Explicit do not publish/do not create must be respected.

## Deliverable
Structurer: the reference tree, numeric proposed budget in minor currency units, destination, reading window, one rationale/signal per decision, and each box's scale/stop plan. Example: CPA below 70% of target over 3 days → consider a 50–100% increase; minimum spend with no result or adverse actual verdict → stop. Separate prerequisites before activation. A reviewable proposal is not remote publication or proof that an image has been produced.
Optimizer: one-line situation, proposal or wait, criterion/signal, fit within approved total and next reading date. Use no unsupported testimonials, results, guarantees or authority. Budget proposals are allowed; invented results are not.
