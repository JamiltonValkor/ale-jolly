# Visual marketing: make the pain and promise visible

English adaptation of existing SaleADS `skills/v2/marketing-visual.md`, part
of the current landing process informed by Santiago Tapias. A landing is a
visual argument for a particular communication bet, not decoration around
interchangeable text. Aim for quick recognition without inventing customer
language or claiming a measured three-second conversion effect.

## Eight principles retained from the existing method

1. **Emphasize the bet's actual pain/desire.** In the headline and two/four
   important phrases, use selective `<mark data-sa-mark>`, weight or an accent
   color. Highlight the few meaningful words, never whole paragraphs. Decorative
   motion is optional enhancement; readable meaning is the default.
2. **Use real customer language.** The questionnaire's voice examples can guide
   a large statement, heading or recognition prompt only when actually sourced.
   A hypothesized objection can be phrased as a hypothetical question, not a
   fabricated quote/testimonial or pretend chat screenshot.
3. **Show the situation before the solution** when it helps awareness: an
   existing relevant photo plus short text, or an honest CSS visual component.
   Do not generate a new scene merely to satisfy the original image recipe.
4. **Make material objections visible.** The original questionnaire names
   three key objections; show those that are supported as clear questions and
   concise answers near their argument, rather than burying all at the end.
5. **Give the promise and mechanism a strong visual hierarchy.** Use meaningful
   contrast; annotate the real product/photo only with supported facts.
6. **Place proof beside action.** A genuine permitted testimonial or real fact
   can answer the nearby doubt. If none exists, use honest process/inclusion
   information rather than manufacturing proof.
7. **Make the actual offer scannable:** real price, correctly computed real
   savings when applicable, included items and relevant conditions.
8. **Sections support one closing:** repeat the configured CTA about every one
   or two useful argument sections when appropriate; a mobile fixed action must
   not obstruct content or add another destination.

Example of the source's highlight technique (illustrative copy only):

```html
<h1 data-edit="hero-headline">
  A promise with <mark data-sa-mark>the relevant customer concern</mark>
</h1>
```

The trusted SaleADS engine can paint the highlight as it enters. Its color is
controlled by `--sa-mark-color` (the existing default derives from the accent).
Do not hide the phrase or author a script to animate it. Use business-locale
copy instead of shipping the example literally.

## Give service pages a visual body

A service often lacks a physical product hero; repeated headings/paragraphs
can make the whole page feel like a document. Preserve the method's objective:
each important section has a visual component that communicates its idea,
and avoid two consecutive sections with the same text-only composition.

Build purposeful components in HTML/CSS using known business information:

- **The customer-question conversation:** a stylized bubble arrangement for
  an actual supplied objection. It is an illustration, never presented as a
  real customer's private conversation or a fabricated testimonial.
- **A plan/document:** a CSS page/card showing actual deliverables, checks or
  process milestones. No invented certification stamps, approvals or numbers.
- **Process timeline:** genuine steps linked visually, with meaningful emphasis
  and no arbitrary numeric decoration.
- **Before/after the consultation:** contrast supported emotional needs and
  knowledge gained where appropriate, not invented physical/financial outcomes.
  Do not create a fake before/after claim restricted by the supplied policy.
- **A genuine figure as a graphic:** verified experience, actual price or
  duration can be typographic material; no impressive number invented for scale.
- **A full-bleed visual interval:** an existing appropriate photo or a truthful
  brand/CSS scene; the original generated-image instruction is disabled here.
- **Large customer language:** sourced wording with correct attribution, or
  clearly phrased non-quoted copy consistent with the canonical bet.

## Template tells to remove

- Tiny uppercase labels above every section title; at most one when it adds
  real navigational/argument value.
- Decorative “01 / 02 / 03” when the content is not a real sequence.
- Identical three-card rows and consecutive flat blocks with the same centered
  heading/paragraph treatment.

Variation must remain coherent with the selected art direction, business
brand, mobile readability and existing photos. Do not replace these visual
craft goals with an unrelated dashboard theme or a generic page template.
