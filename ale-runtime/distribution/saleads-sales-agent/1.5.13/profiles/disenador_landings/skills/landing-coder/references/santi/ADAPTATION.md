# English reference adaptation record

This pilot ports the **actual existing SaleADS references** into English rather
than replacing them with a short generic design prompt. Santiago Tapias is
attributed on his five adapted references. The SaleADS-specific catalog,
visual-marketing and motion-engine documents retain their own source identity.
No new certification, license ownership or provenance is asserted.

The references are available for phase-specific reading; they are not intended
to be injected together into every model request. The integrator owns SKILL,
SOUL, reference links, installation and the root source map. Those files were
not edited by this translation task.

## Execution rules adapted to the actual SaleADS pilot

1. **Who initiates:** the original standalone method speaks to an owner asking
   for a page. Here Ale delegates from an existing bet. Derive questionnaire
   answers from the brief/research; missing facts go back to Ale. Do not start
   another onboarding interview or let a questionnaire override the canonical
   promise, verified facts, policy or platform constraints.
2. **Output/runtime:** preserve HTML/CSS craft and current markup. The pilot
   creates index.html/styles.css only; no React app, JS script, CDN, remote
   font import, arbitrary embed, form or independent hosting/publication system.
   Existing fonts/icons/assets, checker and trusted publisher remain authoritative.
3. **Only existing photos:** source references describing a generated master,
   variations or new scene now map to actual permitted photos or an honest
   CSS/typographic component. Do not invent an asset, product view, person or
   photograph to satisfy an archetype. Missing imagery is an explicit limitation.
4. **Unsupported funnel types:** A–I is retained as persuasive taxonomy, not new
   API enum values or implemented checkout/forms/thank-you/download/calendars.
   Use the actual supplied format and WhatsApp/agenda closing; unsupported
   requirements remain requirements for Ale, not pretend UI/capabilities.
5. **Helper scripts are not installed by reference:** original Node/Chrome and
   review-text/link scripts describe the desired checks. Use actual available
   SaleADS CLI/capture/browser evidence. Do not claim commands ran, extra capture
   widths exist or a page passed checks because a script name appears here.
6. **Capture scope:** preserve the original five-width/full-page/detail target,
   but distinguish the current 390/1440 limited static tiles from complete browser,
   lower-page, intermediate-width, console and actual-motion verification.
7. **CTA exception:** ordinary empty links are errors; SaleADS draft href="#"
   with its configured data-cta is intentional. Do not replace it with a made-up
   contact destination; verify the trusted injected destination after publication.
8. **Default visibility:** the source's IntersectionObserver/class-toggle JS is
   not copied as executable instructions. Use current data-sa-* behavior and CSS
   with complete no-JS/reduced-motion fallback. No meaningful content waits for
   an invented script. CSS recipes are starting points, not mandatory decoration.
9. **Locale/voice:** instructions are English; visitor/owner-facing copy uses the
   supplied SaleADS locale and actual business register. Spanish grammar and
   tú/vos/usted guidance is conditional on Spanish, not a global language choice.
10. **Proof and placeholders:** preserve all truth checks. A missing essential
    fact is reported/omitted rather than exposed as a production placeholder.
    Examples/figures in the reference are synthetic, not evidence. Do not claim
    a minimum guarantee, a customer quote, “most chosen,” availability or payment
    support without a real source.
11. **Practitioner/legal claims:** page-order and copy/pressure advice remains a
    method/heuristic, not proven causal uplift for this business. Historical
    profession/country examples flag a need for actual supplied constraints,
    not a certified current legal interpretation. No new universal policy was added.
12. **Visual rubric:** original section8 uses16/20, no0 and truth2. Existing
    SaleADS phase-revision raises the target to18/20, no0 and2 in1/8/9. This
    difference is preserved openly. Visual review remains consultative; it does
    not replace security/factual validation or the owner's publication action.
13. **Published effects/testing:** no direct publishing, pixel injection, contact
    submission, checkout/payment or conversion noise is created to validate a
    recipe. Existing platform operations and approved tests own those effects.

## What this task did not change or verify

No original web instruction, bundle, model, provider, API, credentials, VM,
SOUL, SKILL or installer was changed. No external model call, image generation,
paid service, publication or live visual/E2E test was performed. Validation is
limited to local source coverage, references/hashes, language review and links.
The integrator must bind these references into the pilot and test their use.
