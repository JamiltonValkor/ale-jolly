# Translate visual craft to the actual publisher

The archive's `assets/base.html`, `references/secciones.md` and `references/movimiento.md` assume a standalone HTML page with custom JavaScript, web fonts, icon CDNs and SaleADS chat components. **Do not copy that runtime into a customer landing.** The existing `landing-coder/references/platform.md` and the actual validator govern the output.

## Preserve the permitted artifact

- Write the existing `index.html` and `styles.css`, stable editable text IDs, catalog font IDs/variables, supported CTA markers and exact authorized asset URLs.
- Ale obtains validation, screenshots, admission and publication state through the existing CLI/Agent API. The specialist does not publish, use internal service credentials, start a server or install packages.
- No custom `script`, inline handlers, arbitrary form/iframe/embed, Google Fonts/CDN imports, remote CSS, copied registration paths or tracking code. The public renderer injects trusted runtime/CTA/pixel/legal elements.
- Source replicas, chat composers, AI selectors, calculators and undo controls are not available platform features. Use an honest static explanation or an existing supported interaction; do not leave fake buttons. A visual illustration is distinguishable from a usable action.

Use the actual photos Ale supplied or deterministically prepared authorized assets. Give each a role and precise crop/object-position in the design plan. Alternatives describe the visible photo in the owner locale.

## Motion should clarify hierarchy

The original separates ambient motion from functional demonstration. Carry that distinction over without importing its orb/chat scripts:

- **Static:** a complete, intentional layout. Essential copy and action are visible immediately.
- **Quiet reveal:** a brief one-time emphasis; the final readable content exists before enhancement. The source suggests about 12–16px travel and 600–800ms, with 60–90ms stagger and a total under one second. Use the existing engine's documented capabilities and adjust for the content.
- **Progress/thread:** a supported declarative sequence can link a real process. If unsupported, show the whole process statically.
- **Pinned or horizontal sequence:** use the existing `data-sa-*` contract only when the content earns it. On narrow screens/reduced motion, preserve a readable linear sequence; never trap required content behind scroll effects.
- **Breathing/accent:** an optional restrained brand treatment, not a default SaleADS orb or perpetual movement everywhere.

Prefer cheap opacity/transform changes. Avoid sustained large filters, layout-property animation, excessive layers and full-page blur. A remaining transform/filter creates a stacking/containing context: confirm sticky actions, overflow and focus are correct in the actual renderer. The source's custom IntersectionObserver/scroll scripts and 250–400vh fixed sequences are not a requirement.

## Reduced motion is a usable final state

With `prefers-reduced-motion: reduce`, stop decorative breathing/rotation/parallax, remove long pinned transitions and expose every step/content item. A reveal must not leave opacity zero or off-screen transforms. Disable smooth scrolling when appropriate; ensure the CTA and anchored section are reachable. If the engine cannot provide the required fallback, choose the static direction.

No essential message waits for typing animation, a countdown or an effect. A label such as “live” requires real live state; animation does not create that fact. Do not use a screenshot taken with reduced motion to claim the moving version was tested.

## Accessibility and responsive checks

Use meaningful landmarks, one h1, the actual page `lang`, title, viewport and accessible labels in the task locale. Preserve keyboard order and visible focus. Decorative icons do not duplicate spoken labels; meaningful icons have names. Do not rely on color or hover alone. Ensure text remains usable at enlarged size and narrow widths.

Use sufficient contrast for **all information needed to decide**: price, conditions, source qualifiers, CTA and body. The source's very faint metadata palette is not a customer accessibility exemption. Resolve actual text/background contrast rather than copying opacity values. Keep long copy to a comfortable line length (roughly 60–70 characters as a reading check), and inspect desktop/mobile line breaks, image crop and horizontal overflow.
